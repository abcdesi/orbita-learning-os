# ORBITA Learning OS — SaaS V2.2

> **Apprends ce qui compte. Dans le bon ordre. Avec la bonne méthode. Jusqu’à vraiment savoir.**

ORBITA est un SaaS familial d’apprentissage adaptatif. Il ne propose pas un énième catalogue de cours : il transforme un objectif en parcours de compétences, vérifie les prérequis, sélectionne une méthode adaptée, exige une preuve de maîtrise, programme les révisions puis ajuste la suite.

## Démarrage Windows — le plus simple

**Prérequis : Node.js 24 LTS ou plus récent.**

1. Décompressez complètement le ZIP.
2. Ouvrez le dossier `ORBITA_SaaS_V2_COMPLETE`.
3. Double-cliquez sur `START_ORBITA_WINDOWS.bat`.
4. Gardez la fenêtre noire ouverte pendant l’utilisation.
5. Le navigateur s’ouvre sur `http://127.0.0.1:3000`.
